# ComfyUI_3D_Texture_Painter_Node
Texture Painter AI paints textures on 3D models right inside ComfyUI. Brush a mask on the model, and Flux.2 Klein 9B repaints it from your prompt. The result is baked back into UV texture layers. It has UV tiles, reference images by angle, a heal brush, object selection, and a standalone editor synced to the node.
